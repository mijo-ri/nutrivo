## Projekt Übersicht

Es soll ein Full Stack Projekt umgesetzt werden, um meine technischen Fähigkeiten
aufzufrischen und neue Skills anzueignen.

Das Ziel ist eine Kalorientracking App zu entwickeln ähnlich wie MyFitnessPal.
Folgende Funktionen soll sie enthalten:
- Essen tracken: Kalorien und Makronährstoffe
- Barcode Scanner um Essen zu tracken
- Voice Tracking. z.B. kann man sagen: "100 Gramm Haferflocken, 4 Eier, 2 Esslöffel
  Olivenöl
- Pro Tag sieht man was man gegegessen hat und wieviele Kalorien und Makros man da hatte

Folgende Technologien sollen verwendet werden.

Backend:
- .NET 10
- Entity Framework
- CQRS
- Clean Architecture
- Domain-driven design

Frontend:
- React Native

Deployment
- Docker
- Github Actions
- Microsoft Azure oder eine freie Alternative
