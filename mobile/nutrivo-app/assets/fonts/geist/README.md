# Geist

Static Regular, Medium, SemiBold and Bold TTF files from
`@expo-google-fonts/geist` version **0.4.2**. The app bundles these files and loads
them with `expo-font`; it does not request fonts from Google at runtime.

- Original project: https://github.com/vercel/geist-font
- Distribution: https://www.npmjs.com/package/@expo-google-fonts/geist/v/0.4.2
- Font license: [SIL Open Font License 1.1](OFL.txt)
